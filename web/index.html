接入你的第一个模块
每个模块一个目录，目录名与清单中的 id 一致。
my_module/
├── manifest.json
└── plugin.py
manifest.json
{
  "id": "my_module",
  "name": "我的模块",
  "version": "1.0.0",
  "description": "这个模块提供的功能",
  "dependencies": []
}
plugin.py
def run(context):
    context.log("模块已启动")
    while not context.wait(5):
        context.log(context.config.get("message", "运行中"))
将这两个文件压缩成 ZIP 上传，用“从文件夹安装”直接选择该目录，或放入 modules/my_module 后刷新发现。安装后依次点击“启用”和“运行”。
依赖模块需先启用并运行。模块是本地 Python 代码，请只安装可信来源；进程隔离不是安全沙箱。完整说明见项目 README.md。

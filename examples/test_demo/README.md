# 接入练习模块

该目录是待接入模块源码，放在 examples 下不会被管理器自动发现。

## 方式一：页面上传

1. 打开 http://127.0.0.1:8765/ 。
2. 点击“安装模块”，选择 `E:\携程\examples\test_demo.zip`。
3. 列表出现“接入练习模块”，初始状态为“已禁用”。
4. 点击“启用”，再点击“运行”。
5. 点击“日志”，查看每 2 秒输出一条信息，默认共 10 条。
6. 约 18 秒后执行结束，页面显示“已完成”。也可以中途点击“停止”。

## 方式二：文件夹接入

将整个 `test_demo` 文件夹复制到 `E:\携程\modules\test_demo`，然后在页面点击“刷新发现”。不要把 ZIP 直接放进 modules，它不会被自动解压。两种方式任选一种即可，同 ID 不允许重复安装。

## 修改配置

停止后点击“配置”，粘贴以下内容并保存，再次运行：

```json
{
  "message": "这是我修改后的配置",
  "interval": 1,
  "count": 5
}
```

运行结果位于 `E:\携程\data\test_demo\result.json`，每次运行覆盖，包含消息、已执行次数、开始/结束时间与状态。状态 `completed` 表示完成，`stopped` 表示被手动停止。

## 卸载与重新接入

点击“禁用”，再点击“卸载”并确认。代码移入 `.trash`，数据、日志与配置保留。再次上传同一 ZIP 时恢复之前配置，但仍默认禁用。

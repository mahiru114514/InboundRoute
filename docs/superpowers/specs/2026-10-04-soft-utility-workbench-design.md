# 行程工作台 · 柔和工具风改造方案

状态：用户已批准方案，改造与桌面/手机验收已完成。详见 `docs/柔和工具风改造验收-2026-10-04.md`。

## 目标与范围

将 `modules/web_workbench/web/` 的行程规划工作台适配为用户提供的 Soft Utility 风格。它面向游客，主要任务是设定行程、选景点、检查冲突、选择交通和下载离线问路卡。

本次针对行程规划主界面及景点详情弹窗。模块管理页面不在本次范围内。保留六个工作区及全部现有数据、按钮事件、表单字段、地图坐标和接口契约。

## 方案比较

| 方案 | 变化 | 取舍 |
| --- | --- | --- |
| A：保留工作流，统一视觉与移动操作（推荐） | 更新色彩、文字层级、控件状态、边界、间距、导航与小屏操作位置 | 接近现有操作习惯，改动集中，便于验证功能兼容 |
| B：地图与日程双栏工作台 | 地图与当天行程并排，其余功能进入辅助区域 | 桌面空间利用更好，需要额外处理地图尺寸、日程切换及小屏排序 |
| C：分页引导流程 | 六个区块拆成分步骤界面 | 首次使用更容易理解，频繁回到设定或交通时增加跳转 |

建议采用 A。用户提供的风格已经确定，不额外更换视觉方向。

## 视觉规则

| 角色 | 色值与用法 |
| --- | --- |
| 页面背景 | `#f4f8f6` |
| 关键正文 | `#203b40` |
| 主行动 | `#2d5b63`，配白色文字 |
| 完成、可用 | `#a9d8cc`，配深色文字与状态标签 |
| 提醒、待确认 | `#f3c98b`，配深棕文字与提示说明 |
| 错误、冲突 | `#e6b7b0`，配深红文字与明确错误描述 |
| 辅助选中状态 | `#b8c9ed`，配深色文字 |

色彩用于传达状态。浅色状态背景上的正文保持足够对比度。边界和分隔保留；文字信息不依赖颜色单独表达。

字体采用已有设备可用的中文无衬线字体，避免外部字体请求和字体加载失败。标题以字重和字号区分层级，不使用营销型巨幅标题。正文约 14–16px，长说明限制行宽，辅助文字保持可读。

主要工作区圆角约 16px，控件约 12px，标签使用较小圆角。仅使用轻微阴影建立层级。原生 CSS 映射参考中的 Tailwind 语义，无需引入新的样式框架。

## 页面与组件

- 顶部：品牌和工作台名称、可用服务状态；与内容区域保持一致的深青色与浅色背景。
- 导航：提供清晰的工作区定位与返回路径。地图、选点、校验和交通保持一键可达。
- 行程设定：优化历史行程工具栏、输入分组、兴趣选择、住宿与离境区域，保持离境区域独占一行。
- 行程概览：日程采用有分隔的紧凑条目，突出日期、顺序和关键状态；避免在大卡片内继续堆套小卡片。
- 景点：保留地图、筛选和横向推荐列表；照片缺失仍明确显示占位，不能用生成图冒充真实景点照片。
- 校验：冲突、待核验和正常结果采用有文字说明的状态色与清晰分隔。
- 交通：突出区间名称、来源、耗时和当前采用方式，保留真实数据与降级状态区别。
- 离线包：操作集中，阅读预览具备适当行宽、分隔与滚动范围。
- 景点弹窗：信息按名称、运营说明、加入操作建立层级，关闭入口始终可见。

## 移动端与交互

小屏改为单列，并为主要保存操作提供底部固定操作栏；预留底部空间和安全区，避免覆盖输入、地图控件或提示。为返回顶部/工作区提供清晰入口。

按钮保持主行动位置一致；按下缩放至 0.98，过渡约 200ms，不采用悬停位移、弹跳或弹性动画。支持减少动态效果偏好。

输入提供默认、聚焦、错误、完成和禁用状态。优先复用浏览器原生校验与现有反馈。删除行程保留确认；保存、计算和下载复用已有一键操作。暂不增加撤销系统或改变后端行为。

## 验证与交付

- 桌面、平板与窄手机宽度检查：无横向溢出、内容遮挡或离境字段重叠。
- 键盘操作、焦点可见、控件标签、禁用状态及减少动态效果检查。
- 检查关键文字与状态文字的对比度，不将灰字放到状态背景上。
- 回归保存/更新、历史切换、地图与筛选、加入景点、规则、交通、离线操作。
- 更新静态资源版本，确保重新打开页面加载新样式。
- 使用隔离演示数据进行视觉验收，不消费真实高德配额或改写用户行程。
- 交付桌面和手机截图及改动说明。

## 规范冲突的处理

参考同时给出 rounded-lg 的示例和 rounded-xl 到 rounded-2xl 的要求：按语义映射为控件 12px、工作区 16px。示例中的薄荷色辅助正文与禁止低对比度文字的要求冲突时，以禁止项为准，使用深色正文，薄荷色作为背景或状态配色。

参考的宽松展示页间距与高频工具的密度要求冲突时，优先保持任务效率。工作区内避免卡片套卡片，采用条目、分组和分隔线。保持已有照片占位和真实数据状态，不能将视觉更新表述为运营数据已核验。

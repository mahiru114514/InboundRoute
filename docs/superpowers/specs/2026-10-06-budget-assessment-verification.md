# 人均费用评估验证记录

2026-10-06，当前非 Git 工作目录实现，未部署。

## 行为

行程概览新增人均整趟费用评估。cost_inputs 保存后动态返回 budget_assessment，分类汇总往返大交通、住宿、当地交通、门票、餐饮、其他和机动费用。缺少价格、分摊参数、路线或人民币币种均保持待补充；模拟价格不会当作真实报价。

房晚独立于酒店停靠，可增删提前入住/延住，按房价 × 房间数 ÷ 人数分摊。打车按车辆数分摊；门票按 stop_id 计入，复用票明确填 0。餐饮可逐日修正。

预算判断区分充足、区间可能超支、预计超支和待补充。行程变更提示核对，已填金额超过预算时仍提示估算超支。建议提供公共交通节省及耗时、住宿/餐饮目标、减少付费游览或调整预算。其他支出已超预算时，明确单项降至 0 无法独立达标。

day.end_transit 保存、刷新恢复、导航读取及重排失效。仅更新费用或预算保留路线。后台更新评估时保留未保存的费用输入。

## 使用

重启本地服务，刷新工作台。保存行程及每人预算后，在概览打开「填写 / 核对费用（人民币）」。填写实际价格并计算交通，点击「保存费用并评估」。空白是未知，不发生的费用填 0。

此次未接入实时酒店、机票或门票询价；价格来自用户估算或当前路线报价，未调用收费地图服务验证实时报价。

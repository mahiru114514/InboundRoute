# 每日独立出发时间

用户要求将每日出发时刻移入每日安排，可逐日不同；直接实施这一明确要求。

移除初始设定里的统一时间字段。新行程仍用09:00默认值；保存全局设定不提交统一出发时刻，保留每一天的配置。展开每日卡片可修改当天时间，修改后自动保存；携带版本校验。失败恢复已保存值并提示，忙碌时阻止重复提交。

PATCH days[] 支持 daily_start_local，不要求同时传景点。只改某一天时仅清空该天旧交通、时间轴及可过期通知，其他天保持原样。之后自动规则校验；缺少交通时明确提示重新计算当天交通，不伪造到达时间。

抵达日实际出发取 max(当天设定, 抵达缓冲结束)。跨零点导致抵达日只有入住时不提供当日时间编辑；卡片说明原因。首日可推迟出发，不能越过必要缓冲。

使用真实HTTP后端测试验证独立保存、无效时间原子拒绝、其他天路线不变及保存全局设定不覆盖；规则测试验证首日下限；隔离浏览器测试验证控件移位、按天修改、不同天时间、刷新恢复、失败回滚与缺交通提示。更新契约时间语义及生成产物，资源版本16。

# 测试反馈改进设计

日期：2026-10-07。依据用户提供的测试反馈，调整费用展示、住宿管理和外币换算。用户已确认整体方案及汇率方式：联网获取参考汇率，并允许手动修改。

## 每日行程与费用

每人整趟费用评估默认折叠，只显示预计金额、预算状态和待补充项数量；点击展开后查看分类、来源、建议和费用编辑。保持费用编辑草稿和展开状态，保存或重算不丢失输入。费用仍按整趟行程评估，不改成每日重复计费。

## 住宿简化

创建行程时通过一个住宿搜索入口选择已预订的酒店或民宿，支持中文、英文和拼音。取消候选/手填模式切换及地图点选。酒店库未收录时明确提示；已有行程中的自填住宿保留名称与原坐标，可在统一搜索中继续使用，不替换成其他酒店。

每日行程默认展示安排，把起终点高级调整与添加住宿/口岸收进折叠入口。住宿可像特殊点位一样插入任意序号，填写休息分钟数，并沿用移除、排序、锁定和跨天移动。

新增住宿停靠区分“途中休息”和“过夜/更换住宿”：休息只参与当天交通与停留，不切换后续住宿，也不重复计房费；过夜更新后续默认住宿。旧行程中未区分用途的酒店点位保持原有过夜继承行为。初始住宿继续作为规划依据，起终点自动派生；高级设置兼容已有明确的每日起终点。

## 人民币与外币

人民币整数分继续作为保存及费用计算基准。页面提供人民币、美元、欧元、英镑、日元、港币、澳元、加元和新加坡元；输入预算可选币种，保存时按当前确认汇率换为人民币。费用总额、分类、余额和节省建议同时显示所选外币近似金额，实际费用编辑保留明确的人民币单位。

通过工作台后端调用 Frankfurter v2 最新参考汇率，显示来源、数据日期和统一口径“1 单位外币 = X 人民币”。允许修改为自定义汇率或重新获取参考值。超时或不支持的返回不伪造汇率；可使用明确标注日期的已有参考值或手填，人民币展示仍可用。

汇率偏好作为浏览器展示设置缓存；切换币种不改已保存人民币金额，不覆盖未保存费用编辑。预算草稿携带币种和汇率上下文，避免刷新后用另一个汇率解读同一输入。汇率请求只接受固定币种，目标 URL 固定，设置超时、响应上限和缓存。

API 依据：[Frankfurter 官方文档](https://frankfurter.dev/)。这是规划参考换算，不提供订房或换汇交易。

## 模块边界与验收

住宿查询和设定留在 anchors/setup，特殊点位操作复用 trip_engine/stops 和日卡；住宿用途进入可选停靠点字段，并同步源契约及生成产物。汇率网络访问独立为工作台后端模块，币种与换算独立为前端共用模块，预算评估器仍只处理人民币。

验证默认折叠及编辑草稿保留、统一住宿搜索与旧住宿恢复、中途休息插入和移除、过夜继承和房费不重复、汇率网络成功/失败/缓存/手改、换算精度及人民币金额保存。运行现有核心回归和真实隔离浏览器，检查手机布局；不操作用户正在运行的服务、配置或行程。

自审：已明确休息与过夜的区别、旧数据兼容、搜索资料覆盖和换算基准。没有新增订房功能，也不承诺未收录酒店可以从任意第三方搜索。

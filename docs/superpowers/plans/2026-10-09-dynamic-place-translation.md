# 动态地名翻译实施计划

目标：每日总览和离线卡片统一使用对应地点的中英文；更换景点后新路线站名、端点及步行地名自动解析；未确认的拼音候选明确标记并可人工确认。

执行方式：当前会话顺序实施，先写并运行失败测试，再实现和回归。当前目录没有 Git 仓库，不执行提交。

- [x] 解析层：保留严格核录匹配；新增有来源和状态的通用解析器，加载景点、酒店、地铁完整译名与本地拼音字典。测试未知名称、改名后的旧英文、同名实体隔离及确认覆盖。
- [x] 打包层：按本次路线收集站名、线路端点、方向和步行地名，补译并汇总待确认和缺失项；按目的地身份核对旧快照，避免使用旧目的地；译名版本写入离线包。

- [x] 缓存：检查包结构版本及译名版本，与行程版本和 TTL 一同判断失效；旧 HTML 提示重新下载。

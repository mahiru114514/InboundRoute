# 入境游工作台语言适配

目标：设置入口提供中文、英语、日语、韩语；切换即时生效且保留表单、行程与浏览器偏好。

实现：独立 `i18n.js` 管理语言解析、词典和文本呈现，保持零构建。通过文本节点和指定可访问性属性的本地化适配现有原生 DOM 渲染；不改表单值、引擎数据或用户输入。使用 WeakMap 保留原始文案，MutationObserver 处理异步更新，切换无需刷新或重算行程。静态文案与常见动态状态共用词典；专有名称保留原文，未翻译资料明确说明。

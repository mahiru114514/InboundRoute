# 动态地名翻译（2026-10-09）

已按用户确认的方案修改携程 v1.5。每日总览、展开时间轴、住宿摘要和路线端点共用地名显示逻辑；英文、日文、韩文模式保留中文并附英文，中文模式显示原名。切换语言只更新对应文字节点，保留表单、焦点、每日展开状态和行程数据。

## 更换游玩地点后的使用方式

1. 更换景点或每日起终点，重新计算受影响日期的交通。
2. 生成离线包。已核录的景点、住宿、地铁站名、线路端点和道路优先使用本地英文。
3. 未核录名称显示拼音候选，并在总览标注 `Unconfirmed`。离线包列出“地名英文待确认”或“部分地名缺少英文”。
4. 展开离线预览下方的“核对地名英文”，填写正确英文，点击“确认英文并更新卡片”。译名保存后重新生成，标题、问路卡和路线地名同步更新；更新失败时仍可再次点击生成。
5. 下载新的 HTML。已下载文件是独立快照，不会自动更新。

当前运行的软件需重启 `route_adapter`、`offline_kit` 与 `web_workbench`，再刷新页面；也可关闭当前 v1.5 软件后重新启动。仅补译既有地点无需重新计算交通；更换实际地点必须重算相关区间。

## 译名来源与边界

- 复用已有景点、核录站名、道路及住宿主数据。
- 导入 [MetroMan 上海站名表](https://www.metroman.cn/en/cities/shanghai/stations)中的 425 个中英文显示名，资料日期为 2026-10-09；标记为 published_english，不创建虚假的站台、方向或出入口记录。
- 图中的昌邑路、迎春路、一大会址·黄陂南路、封浜、桂桥路、康文路、航头均有英文。上海雅居乐万豪酒店复用现有住宿库中的英文；[酒店官网](https://www.marriott.com/en-us/hotels/shamc-shanghai-marriott-marquis-city-centre/overview/)使用 Shanghai Marriott Marquis City Centre。
- 未知名称使用固定版本 [python-pinyin](https://github.com/mozillazg/python-pinyin) 0.55.0 的字典生成本地拼音候选；原始 wheel 的 SHA-256 写在字典中，MIT 许可证随项目保留。运行时不联网，也不需要安装新 Python 包。
- 拼音候选不等同于官方英文，尤其多音字和商家名称需要确认；无法处理的字形明确列入缺失清单。
- 确认译名按城市、地点类型、实体 ID（没有 ID 时用已有坐标）、原名称和目标语言隔离。改名或换地点不会自动套用另一地点的确认结果。已确认译名保存在 `data/offline_kit/place_translations.json`，无需修改行程文件。
- 不同城市的同名地点不借用上海核录表。

## 离线包与缓存

离线包版本升级为 0.3.0，固化译名、确认状态、覆盖报告及译名版本。浏览器缓存同时检查行程版本、译名版本和 24 小时有效期；保存确认译名后，旧包提示重新生成。预览和导出使用相同数据，HTML 无外部脚本、图片或样式依赖。

当前停靠点的名称优先于旧交通快照名称。生成时若发现路线目的地 POI ID 与停靠点不符，会要求重新计算交通，避免新地点卡片带上旧路线。

# 推荐行程使用说明

推荐功能针对上海现有景点库，生成游玩安排；住宿和抵达/返程资料由用户填写。

## 启用与使用

按仓库首页的[启动说明](../README.md)运行整套软件，即可使用推荐功能。

1. 在行程设定填写日期、天数、住宿、抵达口岸与时刻，以及可选返程资料。住宿通过统一搜索选择已预订酒店，支持中文、英文和拼音。当前搜索现有酒店库与已保存住宿；没有匹配时需换关键词，不会自动替换为其他酒店。
2. 选择兴趣与轻松、均衡或紧凑节奏。
3. 勾选希望安排的日期。默认勾选第 2 天至倒数第 2 天；1～2 天行程默认不勾选，需要手动选择。首尾日期也可手动选择。
4. 点击“生成推荐行程”。新行程先计算再整体保存；已有行程使用已保存设定，只补空白且未锁定的日期。设定有未保存修改时，先保存再生成。
5. 查看每个景点的简短介绍、推荐理由与核验提示。简介说明主要看点及游玩方式，便于决定保留或替换；在每日展开行程中也可阅读简介并点击“移除”。生成的景点可以继续删除、换序、移动日期、锁定或调整停留；随后使用现有路线计算、规则检查与费用评估。

没有合适候选时会显示原因。生成或保存失败会保留当前行程；其他窗口修改后，旧推荐不能覆盖新版本，需刷新再生成。

简介覆盖现有 45 个景点；景点列表和详情中同样可查看。历史行程按景点 ID 读取主数据，不需要重新推荐。旧版或外部景点没有简介时显示“简介待补充”。简介的地点事实来源记录在 `modules/trip_engine/data/poi_description_reviews.json`，适合人群与游览安排属于编辑建议。实际开放、票价和预约仍以原有详情及场馆通知为准。

景点卡片默认自动缓慢滚动，到达末端后反向浏览。鼠标放在卡片上使用滚轮后，立即转为按滚轮方向手动浏览，停止操作后也不会自行恢复；触屏操作或键盘聚焦同样接管。可点击“暂停自动滚动”或“恢复自动滚动”。手动浏览到达列表两端时，纵向滚轮继续滚动页面。开启系统“减少动态效果”时，默认不自动滚动。

## 住宿与预算调整

每日“添加住宿 / 口岸”可搜索住宿，指定插入位置和停留分钟数。选择“休息”表示途中回酒店休息，不改变当晚和后续默认住宿，也不额外计房费；选择“过夜住宿”会继承为后续住宿。已有酒店停靠缺少用途字段时保留原来的过夜行为。日卡的起终点调整默认收起，需要时展开。

费用评估默认只显示摘要，展开后可查看分类、来源、调整建议和费用编辑。费用编辑字段明确以人民币元填写。行程设定可选择 CNY/USD/EUR/GBP/JPY/HKD/AUD/CAD/SGD，外币预算按“1 单位外币折合人民币”的汇率换算保存。联网参考值显示来源和日期，可手动修改或更新；获取失败时提示手动填写，已有参考值会标记缓存状态。界面外币金额为近似值，币种切换不会改变已保存的人民币预算。

## 推荐依据

按所选兴趣给景点加分，结合住宿和每日起终点，以距离与等待成本选择顺序；同时过滤已知闭馆、不能满足开放窗口、末入场、停留与返程余量的候选。同一行程不重复安排景点，已安排的日期保持原样。

轻松、均衡、紧凑的每日景点上限分别为 2、4、6。带小孩或长者同行会预留更多交通及休息余量，范围型停留参考值取较长的一端；候选与时间不足时不会强行填满。

交通使用地理距离估算，每日活动暂以 22:00 为上限。推荐不包含实际车次、实时路况、票价、预约名额或整趟预算优化；这些信息仍需现有路线/预算工具和用户核验。开放资料缺失、预约需求与夜景资料不完整会明确提示。

# POI 简介验收

2026-10-06 为两批主数据中的全部 45 个上海景点补齐简短中文介绍，实际长度为 53～64 字。内容概述主要看点、参观方式及适合的游览组合；人民广场上海博物馆与上海博物馆东馆分别描述。地点事实来源见 `modules/trip_engine/data/poi_description_reviews.json`；适合人群与安排属于编辑建议，简介审核不提升开放时间、价格等运营资料的可信度。

与推荐功能实施前的源码备份逐条比对，去除新字段后的两批 JSON 与原数据完全相同，确认 45 条原有字段和值均保留。

## 功能与模块

- 景点列表、详情抽屉、每日展开行程、推荐结果均显示简介；推荐理由单独展示。
- 日卡及推荐结果按 `poi_id` 读取 POI 主数据，历史行程无需重新生成。住宿及口岸停靠点不显示景点简介。
- `poi_content.js` 共用去空白与缺失值提示；旧版或外部数据缺字段时显示“简介待补充”。内容使用 DOM 文本节点展示。
- POI 契约新增可选 `description_zh`，长度 1～120 字，同步 Python/TypeScript/schema 生成产物。行程和推荐方案格式保持原样。
- 静态资源已登记并按依赖顺序加载，缓存版本 v28，页面构建 v12。

# 语言适配说明与验收

## 使用

更新后重启行程工作台，再刷新页面。右上角 **设置 / Settings** 打开设置对话框，在 **Language** 下选择简体中文、English、日本語或한국어。选择后立即生效，点击完成或按 Escape 关闭。

首次使用会按浏览器的语言优先级匹配支持的语言；没有匹配时使用英语。手动选择优先于浏览器语言，在当前站点的 localStorage 中以 `inboundroute.language` 保存。浏览器禁止本地存储时仍可即时切换，但重新打开时可能无法记住选择。

语言切换不刷新页面，不改变行程、表单值、费用币种、北京时间、景点搜索词、选中的推荐日期或当前展开状态。

## 首版范围

翻译工作台的静态界面、表单说明、占位文字、无障碍标签、常见动态按钮、交通状态、费用字段与提示。导出的离线 HTML 使用当前界面语言，中文地名保留，问路句显示中文与所选外语（英文、日文或韩文；中文界面配英文）。离线更新详情见 [离线问路包更新说明](离线问路包更新说明-2026-10-08.md)。

内置 45 个景点的完整简介、全部分类与运营元数据、价格适用范围、推荐理由、安排建议、费用和汇率提示、地图状态与交通导航说明均提供英语、日语、韩语。外部新景点、地图供应商内部界面、第三方路线原始说明和用户自填名称可能保留原文，设置中说明这一范围。后台模块管理控制台供维护人员使用，本次语言功能位于游客行程工作台。

## 维护

- `modules/web_workbench/web/i18n_catalog.js`：中文原文及英语、日语、韩语译文，每行四列；长文案优先匹配，避免分段覆盖。
- `modules/web_workbench/web/i18n.js`：浏览器语言匹配、偏好保存、数字文案模板、文本节点及指定属性的更新。WeakMap 保存原始文案；MutationObserver 接入现有异步渲染，不重新请求或修改行程。
- `data-i18n-ignore`：保留原始资料、名称及问路内容；不应包住需要翻译的按钮或表单标签。所有输入值都不参与翻译。
- 新语言需同时补齐词典列、语言元数据、HTML选项与数字模板。修改资源后统一增加 `index.html` 的 `?v=`。

## 验收

1. 首次使用分别在英语、日语、韩语浏览器中查看初始语言；不支持的语言使用英语。
2. 填写天数、预算和住宿搜索词，勾选兴趣及推荐日期，逐个切换四种语言，核对输入与勾选不变。
3. 选择英语后刷新，确认语言仍为英语；切回中文，确认原始界面文案恢复。
4. 已有行程时展开每日卡片与费用评估，再切语言，确认展开状态、锁定景点及交通方案不变。
5. 在外语模式下改变景点筛选、展开详情、计算交通，确认新生成的常见按钮及提示使用所选语言。
6. 导出离线 HTML，确认文档语言及标题正确，原始地名、中文问路句和所选外语问路句保留；特殊字符被转义。
7. 在窄屏中检查设置入口、语言选择、完成按钮，并按 Escape 关闭，确认焦点回到设置入口。

自动验证：在项目根目录运行 `node tests/i18n.test.js` 和 `python tools/verify_project.py`。

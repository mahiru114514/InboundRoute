# 测试反馈改进验收

日期：2026-10-07。依据用户批准的设计实施费用折叠、住宿简化与外币换算。源码按原有模块职责修改，未操作用户正在运行的服务、配置或行程。

## 使用

- 费用评估默认折叠，摘要显示已计入或预计费用、预算状态和待补充项数；展开查看明细、来源和建议，继续填写人民币费用。刷新评估或修改汇率保留未保存费用输入及展开状态。
- 创建时统一搜索已预订住宿，支持中文、英文、拼音；取消模式切换、手填名称和地图点选。当前覆盖本地酒店资料及已有行程中保存的住宿，不包含任意第三方酒店搜索或预订。搜索无匹配时明确提示，旧自填住宿保留原名与坐标。
- 每日高级起终点调整默认收起。“添加住宿 / 口岸”可搜索、选择插入位置和停留分钟数，住宿用途可选休息或过夜。休息只参与路线和停留，不继承到后续日期，也不增加房费晚数；过夜继承住宿。旧点位缺少用途字段时按原来的过夜行为处理。
- 预算支持人民币、美元、欧元、英镑、日元、港币、澳元、加元和新加坡元。汇率口径是 1 单位所选外币折合人民币，可联网获取并手改。外币预算保存为人民币整数分；总额、分类、余额和节省建议显示外币近似金额。费用编辑仍明确使用人民币元。
- 联网参考值显示来源和日期。失败保留已有值时标记旧日期或手动汇率；没有有效值时提示手填。重置和新建同步控件状态，旧版预算草稿明确按人民币恢复，异步返回不重填已清空预算。

更新后重启行程引擎与工作台，再刷新页面加载新接口及资源。前端资源版本 v31，构建版本 workbench/2026-10-v15。

## 验证证据

`python tools/verify_project.py`：26 组通过、0 组失败。其中 Python 445 项（255 + 79 + 57 + 14 + 40），Node 17 个测试文件，包含契约校验与生成产物同步检查。最终币种边界和异步竞态修复后再次运行全部 17 个 Node 文件通过。

`node tools/verify_recommendations.cjs`：真实 Edge 与临时后端的 49 项浏览器检查通过，无脚本异常。覆盖推荐与简介、自动滚动及滚轮接管、统一住宿搜索、休息插入移除、住宿继承与房晚、费用默认折叠、美元预算转换、手动汇率与网络失败、未保存费用保留、重置和历史新建、获取汇率期间切换行程预算保留，以及 768/390/320px 布局。浏览器汇率使用模拟数据，不访问用户行程。

另通过实际 `CurrencyRates().get('USD')` 只读核验参考源，取得日期 2026-10-07 的有效 USD/CNY 数据。[Frankfurter 官方文档](https://frankfurter.dev/)。服务端固定币种和目标地址，8 秒超时、64KB 响应上限、6 小时内存缓存；无有效数据时不伪造汇率。

规格复审与独立质量复核均通过。审查发现并修复了重置币种显示不同步、旧参考失败日期提示，以及获取汇率时载入新预算导致金额丢失或分值回退的问题。两种预算竞态独立复现及复核，包含 70000/70001 分显示相同外币文字的精度碰撞。休息/过夜继承、错误用途拒绝、汇率缓存/超时/非法数据、鉴权、币种草稿竞态等均有隔离测试。

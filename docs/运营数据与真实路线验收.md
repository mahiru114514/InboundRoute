# 运营数据与真实路线验收

核验日期：2026-10-03。界面和规则演示通过，不等于真实旅行可行性已验证。

当前内置25个POI，14个闭馆状态仍为unverified，8个亮灯窗口为简化演示数据。`closure_data_status=verified`只描述闭馆规则，不证明营业时段、预约、亮灯或落客点全部已核实。检查清单可运行 `python -X utf8 tools/check_operating_data.py`。

本轮已按[上海博物馆官方参观须知](https://www.shanghaimuseum.cn/mu/frontend/pg/m/service/visit-west)修正人民广场馆日场15:00停止入场；普通周一闭馆，国定节假日例外。提前7天预约针对20人及以上团队，已从散客建议移除。保留购票预约提示。2026-07-09至2027-11-14为特展窗口，常设展应前往东馆；指定夜场延长至21:00、19:00停止入场，需要逐日期核实，程序不假设每天有夜场。

来源、核验时间和适用范围保存在 `modules/trip_engine/data/operating_reviews.json`；目前该文件作为核验记录，与种子数据回归测试交叉检查，不能把其中的日场时间套用夜场。核验有期限：展览变更、节假日和临时闭馆都需重新检查。来源只核实武胜路南门入口，尚未证明附近坐标是合法落客区；现有人工落客点继续视为演示建议，不批量编造3至5个“官方落客点”。

后续逐POI维护时先查官网、官方公众号或文旅/政府公告；逐项记录开放时段、适用日期、最后入场、闭馆例外、购票预约、亮灯及合法落客条件。地图POI搜索可补坐标、名称、地址，不能据此把所有运营字段标为verified。建议停留时间是规划估计，照片须确认授权。

真实路线验证使用高德Web服务key；地图JS key不适用。配置及额度说明见[地图接入指引](高德地图接入指引.md)。无需覆盖已有行程，先运行：

```powershell
Set-Location -LiteralPath 'E:\炮房产物\携程v0.5\携程'
$env:AMAP_WEB_KEY="你的Web服务key"
python -X utf8 tools/smoke_amap.py --require-key
```

工具用两个公开景点坐标测试步行、驾车及公交，每种一次；只打印脱敏后的来源、耗时、距离、分段数量，不打印key、请求URL和完整异常。没有key时skipped并返回2；请求失败或字段缺失返回1；三种均得到真实数据才返回0和passed。驾车费用仍可能是估算，不能作为实际网约车报价。

随后另建测试行程，在⑤点击计算，核对来源为amap、选定交通方式后的时间轴、末段口岸路线和离线卡。最后一段交通仍受现有行程契约限制，只在本轮交通面板中展示；刷新后需重新计算，离线包暂不包含末段。这是原有限制，不应把交通面板有方案视为完整离线导航。mock必须保留演示提示，degraded不得被当作真实结果。

本轮当前环境没有AMAP_WEB_KEY，工具返回skipped，**未实测三方API**。合成数据覆盖交互、异常和降级；官方记录覆盖已核实运营字段；真实API验收待有效key可用后执行。

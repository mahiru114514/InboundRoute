# 离线问路包 0.2.0

本次按 `携程` 文件夹的当前工作台、每日锚点、住宿停靠和语言设置同步离线生成与下载功能。

## 使用

1. 重启 `offline_kit` 和 `web_workbench`（也可重启整套软件），刷新工作台。
2. 在设置的 Language 中选择简体中文、English、日本語或한국어。
3. 对需要离线携带的行程，计算全部区间交通、处理待确认冲突，再点击“生成离线包”。
4. 点击“下载问路卡 HTML”。生成后的 HTML 使用当前语言，可在本地服务关闭、无网络时打开，也可打印。

切换语言会立即重新渲染已经载入的离线预览，无需重算路线；重新下载才能改变此前导出文件的语言。旧文件与旧浏览器快照不会自动补齐数据，需要重新生成。

## 内容

- 每天日期、计划开始时间、实际起终点；酒店变更按现有每日解析结果继承。
- 景点、酒店休息与过夜停靠，到达、离开、停留时间。统一使用北京时间（UTC+8）；跨日时附实际日期。
- 已选交通方式与耗时，包括最后一站到当天终点的 `end_transit`；无景点但换酒店的日期也包含交通。
- 已保存的中英文站名、线路号与颜色、进出站口编号、步行距离和中英文方向/换乘提示。
- 问路卡显示中文与英文、日文或韩文。中文供当地人阅读，原始中文及英文地名保留；中文界面配英文问路句。

必要终点交通缺失时，服务拒绝生成并提示计算。旧快照缺少新字段时，预览提示资料待补充和终点交通缺失，不把缺失信息视为无需交通。空日且起终点相同可无需额外交通。

保留行程版本绑定、24 小时 TTL、5MB 限制与演示路线标记。HTML 内嵌样式，使用系统字体，不含外部脚本、图片或网络资源。所有行程文字均转义；实时公交、拥堵和多方案对比不会导出。原始方向资料保留中英文，未保存的出入口与方向不会编造。

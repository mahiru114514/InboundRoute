| 离境展开与每日出发重叠 | fieldset占整行，内部独立网格，hidden显式隐藏；同时修复窄窗历史下拉、每日卡片等固定宽度溢出 |
| 景点列表刷屏 | 单行横向滚动卡片，保留搜索、类别、兴趣排序和详情；用“暂无照片”文字图形占位，简介取类别、标签和时长，不伪造照片 |

| 草稿与自动保存兼容 | 草稿关联trip_id；新建草稿刷新后不会误选旧行程，历史切换丢弃上一份表单草稿 |

| 主路线与变体次序 | 主路线指标按主方式选取；请求modes顺序为taxi/transit时不会把打车耗时标作公交 |
| poi_cap优先级笔误 | 使用明确的缺省均衡建议上限4；空日和arrival_only既有行为保留 |
| 契约版本混用 | registry、健康信息、路线/离线响应版本统一0.3.2；补齐trip_engine健康数据中的版本；真实HTTP集成验证注册与健康相同 |
| 两套服务测试临时目录泄漏 | TemporaryDirectory + addCleanup，先登记目录回收，再登记假服务和业务服务停止；正常结束以及setUp后续失败均会执行清理 |
| 文档路径/标题 | 地图指引两处启动目录改为真实工程路径，区分JS/Web服务key，纠正“免费日配额”及默认瓦片必然免费授权的断言；功能清单更新v0.5并保留历史段落 |
| 探针残留 | 已删除外层_probe2、_probe3、.tmp、tmptest及docs/_probe.md；旧审查脚本已归档到docs/audit/audit_reproduce_before_fixes.py，仍只代表旧故障，不应作为通过判据执行 |

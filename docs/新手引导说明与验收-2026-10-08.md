# 新手引导说明与验收

日期：2026-10-08。

## 详细讲解版更新

根据用户选择，保留五步弹窗，增加五章目录、20 条操作要点、5 个说明示例与 10 个可展开问答。内容覆盖日期与酒店选择、预算口径、推荐日期、已有安排保留、锁定与跨天移动、休息与过夜、交通重算、费用分摊与留空/0、离线生成与文件保存。

点击目录可直接查看某章；切换章节收起上一章的问答并滚动到顶部。切换语言保留当前章节、展开问答和阅读位置。标题、目录和底部按钮保持可见，正文独立滚动；手机目录可横向滑动。

示例不会写入表单或行程，费用示例只解释分摊，不是报价。沿用已看版本 1，之前关闭引导的浏览器不会因文案更新再次弹出；通过右上角“使用引导”查看新版。

新文案由独立 `onboarding_content.js` 注册进四语字典；加载顺序和实际 HTTP 获取已纳入验证。增强测试覆盖目录跳转、当前章节标记、详情完整性、全部问答的英语覆盖、语言切换保留展开与滚动、手机长文滚动及离线问答。桌面与手机截图已更新，另保存 `onboarding-preview/onboarding-mobile-en-faq-2026-10-08.png` 展示展开问答。


## 使用方式

重启 `web_workbench` 并刷新页面。当前浏览器首次使用新版引导时会自动打开五步弹窗：设定行程、挑选景点、每日安排与交通、提醒与费用、离线问路。右上角“使用引导”可随时从第一步重新查看。

可以使用上一步、下一步、跳过、关闭按钮或 Escape。跳过、关闭和完成会在当前浏览器记住已看状态，刷新后不会重复弹出。最后的“去设置行程”会展开、定位并聚焦行程设定。

内容跟随设置中的简体中文、英语、日语、韩语；切换语言保留当前步骤。浏览器禁止本地存储时仍能查看、关闭与重开，但跨刷新无法记住已看状态。清除浏览器数据也会重新显示。

## 实现

- 独立 `modules/web_workbench/web/onboarding.js`，在网络请求之前初始化，不修改行程和表单草稿。
- 原生 dialog 支持键盘操作；正文可滚动，底部操作保持可见。
- 静态资源统一更新为 v=35，HTTP 静态挂载加入 onboarding.js。
- 存储使用 `inboundroute.onboarding.seen`，当前版本 `1`。

## 验证证据

- `node tests/onboarding.test.js`：首次展示、幂等初始化、前后步边界、完成/跳过/关闭/Escape 持久化、重看、存储异常、聚焦行程设定、四语重绘及页面 ID 唯一性。
- 全部 20 个 `tests/*.test.js` 前端测试文件通过；工作台接线测试包含 136 项，覆盖原有行程恢复、草稿、推荐和编辑等功能。
- `python -m unittest discover -s tests -p test_web_workbench.py`：26 项通过，包含页面引用静态资源可通过真实 HTTP 获取。
- `tools/verify_onboarding_browser.cjs` 使用真实工作台 HTTP 服务、临时数据目录和独立 Edge 浏览器配置：五步操作、四语文案、关闭后焦点、原生 Tab/Escape、草稿保留、完成后定位、刷新不重复与手动重开、禁止存储时交互均通过。
- 验证尺寸：1280×800、390×844、320×568、667×320。弹窗与底部按钮位于视口内，无弹窗横向溢出，浏览器无 JavaScript 异常。
- 浏览器验证时后端业务服务刻意缺席，验证引导不依赖其运行；未对用户正在运行的服务或行程进行写入。

可复现命令：

```powershell
node tools/verify_onboarding_browser.cjs '<playwright 模块目录>' 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
```

Python 默认使用 `python`，也可通过 `ONBOARDING_TEST_PYTHON` 指定。

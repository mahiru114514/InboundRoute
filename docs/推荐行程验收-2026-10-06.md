# 推荐行程验收记录

用户确认第一版规则推荐方案后，完成推荐插件、原子保存接口、工作台入口与自填住宿。推荐结果只覆盖选中的空白未锁定日期；酒店及抵达/返程资料由用户填写，景点可继续编辑。

## 实现边界

- `modules/recommendation_engine/` 独立计算，通过 HTTP 读取行程引擎，按兴趣、距离、停留、开放与出行边界规划。
- `core/poi_availability.py` 共享闭馆及开放例外判定，保持原规则模块语义。
- `modules/trip_engine/recommendations.py` 先完整校验，再一次创建或提交；已有行程必须携带源版本。
- 工作台新增 `recommendations.js`，默认中间日期、自填住宿名称和地图位置、原因和核验提示；全部资源版本统一为 27。
- 使用现有行程与停靠点格式，推荐点默认未锁定。计算失败不留空壳，旧版本不能覆盖用户编辑。

## 审查修复

增加针对性先失败再通过的用例，修复未选中空白锁定日被状态刷新解锁、请求生成模型丢失 setup、无法保存的隐式等待、跨夜末入场与非法非 ASCII 令牌响应。前端补充计算/保存期间切换行程或更改设定的保护，推荐解释移到折叠表单外。

## 使用限制

当前景点库为上海。交通为距离估算，日活动上限暂为 22:00，不推断前一日跨夜营业；需再计算真实路线。推荐不优化整趟预算，不提供机票、订房或预约，资料缺失与费用由用户核验及补充。未自动重启用户服务。

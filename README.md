# IboundRoute · 体验版

在自己的电脑上规划上海行程：选择景点、安排每天的路线和住宿、查看参考费用，并下载可以离线打开的多语言问路卡。界面支持简体中文、English、日本語和한국어。

## 下载与启动

需要 Python 3.10 或更新版本，无需安装第三方 Python 包。Windows 安装 Python 时请勾选 **Add python.exe to PATH**。

1. 点击 [下载体验版 ZIP](https://github.com/mahiru114514/IboundRoute/archive/refs/heads/main.zip)，或在仓库上方选择 **Code → Download ZIP**。
2. 解压到本地文件夹，找到 `start_software.bat`。
3. 双击 `start_software.bat`。首次启动出现“要启用并启动全部模块吗？”时，输入 `y` 并回车。
4. 等待浏览器打开行程工作台，按照首次显示的使用引导操作。运行期间保持启动窗口打开。

再次使用时，双击同一个文件即可。结束体验时，在启动窗口按 **Ctrl+C** 停止服务；只关闭浏览器标签页不会停止程序。

如果使用终端，请在解压后的项目目录运行：

```bash
python start_software.py --all
```

macOS、Linux 也可使用上面的命令；如果系统的 Python 命令是 `python3`，请改用 `python3 start_software.py --all`。

## 第一次体验

1. 填写游玩日期、天数、住宿及抵达/返程资料。
2. 选择兴趣和游玩节奏，勾选希望安排的日期，再点击“生成推荐行程”。1～2 天的行程需要手动勾选日期。
3. 展开每日行程，查看景点介绍，按需要移除、换序或调整停留时间，再计算交通。
4. 查看费用评估，补充自己的实际预算、门票和住宿费用。
5. 在设置中切换语言，生成并下载离线问路包。下载的 HTML 文件可以在没有本地服务和网络的情况下打开。

页面右上角的“使用引导”可以随时重看。详细操作见 [推荐行程使用说明](docs/推荐行程使用说明.md)。

## 地图与参考信息

直接启动即可体验行程编排、景点介绍、预算和多语言界面。高德官方地图及在线路线需要配置自己的 Key，步骤见 [高德地图接入指引](docs/高德地图接入指引.md)。仓库不包含可共用的地图密钥；未配置在线路线时使用演示数据，请勿据此实际导航。

当前内置上海景点及部分住宿资料。推荐安排、交通估算和费用用于规划参考，实际开放时间、预约、票价和路线请以场馆或交通服务的信息为准。

## 常见问题

- **启动提示找不到 Python**：确认已安装 Python 3.10+，并已加入 PATH；安装后重新打开启动文件。
- **没有自动打开行程页面**：查看启动窗口里的“软件主界面”地址，复制到浏览器。`http://127.0.0.1:8765` 是模块管理控制台，行程页面使用启动窗口显示的地址。
- **提示端口被占用**：先关闭上次的启动窗口，再重新启动。`start.bat` 用于模块管理，请与 `start_software.bat` 二选一运行。
- **地图没有显示或在线路线失败**：检查自己的地图 Key、网络及配置；参照上面的地图接入指引。
- **保存的行程在哪里**：程序保存在本地 `data/` 中，配置在 `config/` 中。更新版本时请保留这两个文件夹；分享程序时可删除自己的数据和配置。

遇到问题可在 [Issues](https://github.com/mahiru114514/IboundRoute/issues) 反馈，说明操作步骤和报错文字。截图前请遮住个人行程与地图密钥。

Windows 双击 `start.bat`，浏览器自动打开 http://127.0.0.1:8765 。启动窗口保持打开即可，不需要输入命令。页面左下角可关闭管理服务。关闭浏览器标签页不会关闭服务。

1. 内置“心跳示例”，点击**启用 → 运行 → 日志**即可观察输出。
2. 点击**安装 ZIP**（选择 `examples/greeting.zip`）或**从文件夹安装**（直接选择模块目录，无需打包）。交付测试已安装“问候卡片”；如需重复体验，先禁用并卸载它，再重新安装（原数据和配置保留）。
3. 模块安装后默认禁用。**启用**允许使用，**运行**开始执行；一次性任务正常返回后显示“已完成”。
4. **配置**接受 JSON 对象。运行中禁止修改，停止后保存，下次运行生效。
5. **禁用**会停止模块并保存禁用状态。**卸载**要求先禁用，代码移入 `.trash/`，保留 `data/`、`logs/`、配置，重装同 ID 可继续使用。
6. 也可将模块文件夹放入 `modules/`，点击**刷新发现**。不要直接删除或修改正在运行的模块文件。

管理服务重启后保留启用状态和配置，但不会自动运行模块。模块源码更新需要先停止再替换，下次启动使用新代码；不提供运行中热更新。日志最多保留三个约 1 MB 文件，页面显示当前文件最近 64 KB。

## 两个入口，别同时开

| 入口 | 用途 |
| --- | --- |
| `start.bat` / `manager.py` | **管理控制台**：模块列表、手动启用/运行/停止/卸载、改配置、看日志 |
| `start_software.bat` / `start_software.py` | **启动整套软件**：读同一份 `config/state.json`，按 `dependencies` 顺序自动启用并启动已启用的模块，对声明了 `service` 的模块做 `/health` 检查，最后打开主界面 |

两者共用 `config/state.json` 与 `modules/`，**同时运行会互相打架**（端口占用 + 状态竞争），请二选一。

## 服务型模块会在卡片上显示端口与健康状态

模块清单里声明 `service` 后，管理页面的模块卡片会多出一行状态（契约见 `contracts/MODULE_RUNTIME.md` §2.5）：

```json
"service": { "enabled": true, "health_path": "/health", "open_path": "/", "title": "行程工作台（软件主界面）" }
```

卡片显示 `服务端口 51234 · /health 健康`；未注册端口时显示「未注册端口」，端口在但服务无响应时显示「无响应」。
注册文件放在 `data/_registry/<模块ID>.json` 或模块自己的 `data/<模块ID>/registry.json` 均可，共享目录优先。


## 开发模块

目录名必须与 `id` 相同，ID 为小写字母开头的字母、数字、下划线，最长 64 位。

`modules/my_module/manifest.json`：

```json
{
  "id": "my_module",
  "name": "我的功能",
  "version": "1.0.0",
  "description": "功能说明",
  "dependencies": []
}
```

`modules/my_module/plugin.py`：

```python
def run(context):
    context.log("已启动")
    while not context.wait(5):
        context.log(context.config.get("message", "运行中"))
    context.log("已停止")
```

所有模块实现 `run(context)`：

| 接口 | 用途 |
| --- | --- |
| `context.config` | 本次启动时的 JSON 配置快照 |
| `context.data_dir` | 模块专属 `pathlib.Path` 数据目录，已自动创建 |
| `context.log(message)` | 写入可在管理页面查看的日志 |
| `context.should_stop()` | 检查是否收到停止请求 |
| `context.wait(seconds)` | 可被停止信号打断的等待，收到停止信号返回 True |

一次性任务可以直接返回；长期任务应定期检查停止信号。停止操作先请求协作退出，2 秒后仍未退出则终止模块进程。模块应在退出时释放自己的资源，不应遗留自己创建的子进程。管理器管理的是模块主进程，不负责清理插件自行脱离的外部进程。

支持模块内部相对导入，例如 `from .helper import calculate`。模块使用独立进程，不能通过 Python 全局变量互相调用；首版 dependencies 管理启动前置条件，不提供跨进程服务注册或消息总线。

`dependencies` 是模块 ID 列表。依赖必须先安装、启用和运行；禁用/停止时按反向顺序操作。有任何已安装模块声明依赖时，禁止卸载被依赖模块。启动会检查缺失依赖及循环依赖，不自动操作其他模块。运行中依赖退出，会在使用它的模块卡片上显示提示，不自动重启或停止其他模块。首版不解析版本约束，也不自动下载 Python 包。

## 安装方式与目录规范

模块根目录必须直接包含 `manifest.json` 和 `plugin.py`；如果只含唯一一层模块目录（ZIP 常见的打包方式），也会自动识别。两种安装方式共用同一套校验和落位流程，安装后都默认禁用：

- **安装 ZIP**：上传符合规范的压缩包，自动解压安装。ZIP 可以不带那层目录。
- **从文件夹安装**：直接选择本地模块文件夹，跳过打包，便于本地开发反复迭代。文件夹名必须与清单 `id` 一致，否则拒绝安装。

限制与安全规则：

- ZIP 上传最大 20 MB，文件夹内容最大 80 MB，解压后最大 80 MB，最多 2000 个条目。
- 拒绝路径穿越、绝对路径、反斜杠、Windows 保留名、符号链接、特殊文件、加密文件及重复路径；非 UTF-8 文本文件无法安装。
- 安装时忽略 `__pycache__/`、`.git/`、`*.pyc`、`*.pyo`，避免本地缓存影响安装。
- 临时解压并验证通过后才移动至 `modules/<id>`；同名模块不会覆盖，需要先禁用并卸载。
- 只安装可信模块：模块会以当前用户权限执行 Python 代码，独立进程不是安全沙箱。

两种方式在页面上分别对应右上角的**安装 ZIP**和**从文件夹安装**；接口层面则是 `POST /api/install`，通过 `X-Install-Format` 头区分：`zip`（默认，请求体是压缩包字节）或 `folder`（请求体是 `{"folder": "模块目录名", "files": {"相对路径": "base64 文本"}}`）。

node tests/map_states.test.js         # 图钉状态机 / GCJ-02 / 密集簇 / 锚点

> 再模拟点击「锁定 / 计算交通 / 加入行程」等按钮，断言请求确实发出、面板确实渲染。

地图坐标自检（`tools/check_poi_crs.py`）：

```powershell
python tools/check_poi_crs.py                        # 校验种子坐标画到高德底图上的落点
python tools/check_poi_crs.py --hint 31.2397,121.49  # 把地图上量到的 GCJ-02 坐标反解成应填的 WGS84
```

> 坐标体系：内部主数据一律 **WGS84**，高德/腾讯瓦片是 **GCJ-02**，转换只由客户端单向完成
> （见 `contracts/mappings.json#/crs_conversion`）。**不要把高德/百度地图上直接抄来的坐标填进种子文件**——
> 那些是 GCJ-02/BD-09，会被再转一次，导致图钉整体偏移数百米。回归测试：`tests/test_poi_crs.py`。

前端资源带缓存开关：改动 `modules/web_workbench/web/` 下的任何脚本或 `style.css` 后，
把 `index.html` 里 `?v=` 后面的数字 +1（所有资源要用同一个数字），浏览器才会强制拉新文件
（控制台会打印 `[workbench] build ...`、`[IRMap] build ...` 便于确认版本）。

页面脚本加载顺序有依赖，不要随意调整：`runtime.js` 首先提供共享状态和基础工具，
随后按 `index.html` 加载离线缓存、流程、地图与功能脚本，`app.js` 最后执行 `boot()` 恢复历史行程。
新脚本同时登记到 `engine.py` 的 `ASSETS` 和 `index.html`；测试会读取这两处来验证资源和加载顺序。

指定其他端口：`python manager.py --port 8766`；不自动打开浏览器：`python manager.py --no-browser`。

服务只监听本机回环地址，写操作要求页面令牌且校验同源请求。该版本用于单用户本机管理，不用于公网或多人远程管理。只启动一个服务实例，避免多个管理器同时写入同一份配置。若端口被占用，请先检查原管理页面是否已经打开。

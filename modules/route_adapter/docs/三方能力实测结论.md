# 三方能力实测结论（开发者 C / C10）

> 结论口径：本环境未配置高德/腾讯/百度 API key，**无法发起真实网络请求**。以下结论以
> `contracts/mappings.json#/provider_field_map` 已登记的字段可得性 + 各家公开能力边界为基准，
> 与「不留假数据」原则一致：**不可得字段一律不伪造，返回 `null` 并走对应降级路径**。
> 待接入真实 key 后，可按本表逐条复测并回填 `provider_field_map`。

## 一、14 条结论

| # | 能力 | 结论 | 处理 |
| --- | --- | --- | --- |
| 1 | 换乘段步行距离 | 高德/腾讯可返回，百度公交方案需实测 | Adapter 归一化 `walking_distance_meters`；缺失返回 `null` |
| 2 | 进出站口编号 | 三家公交 API 一般不返回 | 仅由 `CuratedStation` 提供；缺失时 `source` 缺失 → 前端隐藏该行 |
| 3 | 站台方向/线路颜色/英文名 | 线路颜色通常不返回 | 颜色/方向由 `CuratedStation` 提供，三方缺失返回 `null` |
| 4 | 推荐落客点 | 打车 API 部分返回，粒度不保证 | 保留人工 `suggested_drop_off`，不做强制重映射 |
| 5 | 拥堵等级枚举 | 各家不一致 | 统一为 `congestion_level` 枚举；缺失 `unknown` |
| 6 | 打车费用区间 | 高德/腾讯可返回区间 | `cost.min/max`；缺失返回 `null` |
| 7 | 实时公交覆盖/刷新 | 城市覆盖差异大 | 缺失走 `realtime_transit` 降级（计划时刻表） |
| 8 | 入参/返回坐标系 | 高德/腾讯 GCJ-02，百度 BD-09 | Adapter 单向转 WGS84（`crs.py`），客户端不转换 |
| 9 | 逆地理编码粒度 | 高德/腾讯 POI/道路级 | 失败走 `reverse_geo` 降级（手动打点） |
| 10 | POI ID 稳定性 | 各家 ID 不稳定 | 内部 `poi_id` + `provider_refs` 映射，不直接落三方 ID |
| 11 | 结果长期存储许可 | 需商业授权 | 离线包短 TTL（24h）+ 体积上限 5MB |
| 12 | 配额/QPS/计费 | 免费额度有限 | 调用预算 ≤4/次、并发 4、缓存 TTL 1800s、429 不重试 |
| 13 | 室内换乘/扶梯提示 | 公交 API 不返回 | 归入 `CuratedStation.interior_transfers` + `vertical_gap_note` |
| 14 | 步行路径物理约束 | 一般只给直线距离 | 长换乘判定用 `walking_distance_meters` 原始值，不做越江/过桥推断 |

## 二、回填的 provider_field_map（不可得字段）

见 `modules/route_adapter/data/provider_capabilities.json`。核心不可得字段：

- `access_points.access_no` / `access_points.landmark_desc` → 仅 `curated`，三方不提供。
- `interior_transfers.walking_distance_meters` / `note_en` → 仅 `curated`。
- `lines.directions[].name_en` / `lines.color_hex` → 仅 `curated`。

这些字段在 Adapter 输出中若三方来源缺值，一律 `null`，**不填充占位或假数据**。
